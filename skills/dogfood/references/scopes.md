# Select the destination

| Evidence | Destination |
| --- | --- |
| One product defect or missing feature | Product code, configuration, or a meaningful check. |
| Repeated procedure in one project | Existing project script, skill, or instructions. |
| Method shown to apply across projects | Personal skill or concise global instructions, with exceptions. |
| Agent execution or setup failure | The accessible harness code or configuration that causes it. |
| Dogfood fails to find, apply, check, or retain an improvement | Dogfood source instructions or skills, with a fixed evaluation. |
| Uncertain benefit, missing access, or stale evidence | A deferred or blocked finding with a resume condition. |

The current user task remains authoritative. Use the smallest scope supported by evidence. Merge with an existing authoritative rule rather than adding contradictory instructions. Preserve explicit user choices. A workaround from one project does not justify a global rule. Do not change billing, publication, external messaging, or permissions merely because a finding recommends it.
